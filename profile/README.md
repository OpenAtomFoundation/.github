# About Us

The [OpenAtom Foundation](https://openatom.cn/) is a non-profit organization dedicated to advancing the global open source cause. It was established in Beijing in June 2020. Upholding the core philosophy of "co-building, co-governance, and sharing", the Foundation positions itself as a developer-centric open source project incubation platform and a technology-for-good service organization. It aims to systematically build an open and collaborative open source ecosystem, improve industry collaboration efficiency, empower all sectors, continuously enhance China's influence in the global open source community, and contribute to a prosperous open source ecosystem.

## Open Source Projects

The Foundation continues to build a development system for open source projects, refine its strategic project portfolio, and incubate and nurture open source projects.

### Archived Projects

> Note: Every open source project has its life cycle and may become less active for various reasons. Within the OpenAtom Foundation, projects in the incubation stage must meet a number of requirements. According to Article 12, Chapter III of the OpenAtom Foundation Open Source Project Management Policy v1.0, an incubating or graduated project shall be archived by the Secretariat under any of the following circumstances:<br>
> (1) The project maintenance team is dissolved;<br>
> (2) The donor or the project's open source governance body submits a project archival proposal to the Secretariat;<br>
> (3) The project has no code commits or maintenance activity for one year and remains unmaintained after notification.<br>
> Once a project is archived, the OpenAtom Foundation will no longer provide full services for it, such as brand marketing and developer events. The trademarks and code of archived projects remain hosted by the OpenAtom Foundation in a neutral manner, and the project repositories are set to read-only. If you are interested in taking over the operation of an archived project and restarting it, please contact <operation@openatom.org>
